1. Scope / دامنه کاربرد

۱. دامنه کاربرد / Scope

This specification defines the material, dimensional, and performance requirements for the 500mm control valve (VALVE-500-CTRL) used in the Gachsaran Oil Refinery Expansion Project, in accordance with ASME B16.34 and API 598. این مشخصات، الزامات مواد، ابعاد و عملکرد شیر کنترلی ۵۰۰ میلیمتر (VALVE-500-CTRL) مورد استفاده در پروژه توسعه پالایشگاه گچساران را مطابق با استانداردهای ASME B16.34 و API 598 تعریف می‌کند.

4. Quality Assurance / تضمین کیفیت

۴. تضمین کیفیت / Quality Assurance

All valves shall be inspected and tested in accordance with the approved Inspection & Test Plan (ITP) and shall be accompanied by a Certificate of Conformance (CoC) and a Hydrostatic Test Report. تمام شیرها باید مطابق با برنامه بازرسی و تست (ITP) تأیید شده، بازرسی و تست شوند و همراه با گواهی انطباق (CoC) و گزارش تست هیدرواستاتیک ارائه گردند.

Note: Any deviation from this specification requires written approval from the Engineering Manager and must be documented in an Engineering Change Order (ECO).
توجه: هرگونه انحراف از این مشخصات نیازمند تأیید کتبی مدیر مهندسی بوده و باید در یک دستور تغییر مهندسی (ECO) مستند شود.
