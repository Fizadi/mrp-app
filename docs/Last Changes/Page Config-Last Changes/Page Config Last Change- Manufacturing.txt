21. Shop Floor Control

Element                Specification
---------------------  ----------------------------------------------------
Page Type              Transactional / Real-time (MTS-ready, v47)
Purpose                Real-time production execution per workstation 
                       with Lot/Batch reporting.

Key Features           - Operator workbench
                       - Lot-based reporting (operator sees lots, 
                         not job orders)
                       - Start/stop job per operation
                       - Input/Output/Scrap quantity per operation
                       - Scrap reason capture (from t_ScrapReason)
                       - Downtime logging
                       - Self-inspection with batch sampling
                       - Backflush trigger on operation completion
                       - Barcode / traveler card input
                       - Machine integration

Top KPI Cards          Active Jobs / Completed Today / 
                       Downtime Today / Yield% Today

Main Table Columns     Lot ID (link), Job Order (link), Operation,
                       Workstation, Status, Input Qty, Output Qty,
                       Scrap Qty, Yield %, Operator, Actions

Action Buttons         Start Lot (modal), Complete Operation (modal),
                       Report Quantity (modal), Log Downtime (modal),
                       Self-Inspect (modal), Split Lot (modal)

Modals                 - Start Lot      : select lot, confirm start, 
                                          assign machine
                       - Complete Op    : Input Qty, Output Qty,
                                          Scrap Qty, Scrap Reason,
                                          Rework Qty, Notes
                       - Report Qty     : qty good, qty scrap, 
                                          rework flag
                       - Downtime       : reason, duration, machine
                       - Self-Inspect   : sampling result, notes
                       - Split Lot      : source lot, split qty, 
                                          new lot destination

Filters                Workstation dropdown, Shift dropdown, 
                       Operator dropdown, Lot Status dropdown

URL Parameters         workstation_id, shift, operator_id, lot_status

URL Example            /manufacturing/shop-floor?workstation_id=WC-CNC-01&shift=1

UI/UX                  Large touch-friendly buttons. Lot barcode field 
                       auto-focused. Real-time yield bar. Color-coded 
                       status badges. Warning banner if scrap > threshold. 
                       RTL/LTR support.

Navigation             Lot ID → Lot Detail (future). 
                       Job Order ID → Job Orders (new tab on Ctrl+Click).

DB Tables              t_ProductionOrder, t_ProductionOrderDetail,
                       t_WorkCenter, t_Machine, t_Users,
                       t_ShopFloorTransactions, t_ScrapReason,
                       t_Lot, t_QualityInspectionResult

API Endpoints          GET  /api/manufacturing/shop-floor/jobs
                       GET  /api/manufacturing/shop-floor/lots
                       GET  /api/manufacturing/shop-floor/stats
                       POST /api/manufacturing/shop-floor/start
                       POST /api/manufacturing/shop-floor/complete-op
                       POST /api/manufacturing/shop-floor/quantity
                       POST /api/manufacturing/shop-floor/downtime
                       POST /api/manufacturing/shop-floor/inspect
                       POST /api/manufacturing/shop-floor/split-lot
                       POST /api/manufacturing/shop-floor/merge-lot

Dependencies           Job Orders, Job Order Detail, Workstations,
                       Machines, Work Center Routing, 
                       Inspection Workbench, Inventory
